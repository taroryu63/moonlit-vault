Moonlit Vault is a top-down stealth game set in a moonlit vault. Slip past patrolling guards and their vision cones, use cover and shadow tiles, collect the Moon Shards, and reach the exit unseen. Three levels with rising guard counts, a detection meter, and sound generated entirely in code with WebAudio — no external assets, no libraries.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a desktop browser
```
